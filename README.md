<details>
<summary><strong>Hydrolink</strong>: An IoT irrigation platform built from ESP32 firmware to mobile app</summary>

<br>

Hydrolink started with a practical need: managing irrigation on a countryside property without having to check on it constantly. I built the platform across the React Native app, Spring Boot backend, and ESP32 firmware.

**Features:**
- Register and sign in, then link or unlink irrigation areas using a QR code or link code
- See owned areas, live status for their stations, and upcoming watering schedules
- Start and stop supported stations remotely, with the app showing pending state until the device confirms the change
- Set per-day watering schedules with fixed or relative time windows, and see reported conflicts
- Get firmware update notifications and start an over-the-air install from the app
- Use the app in English or Spanish

**Tech:** Java/Spring Boot · React Native (Expo) · TanStack Query · PostgreSQL · Redis · AWS IoT Core · AWS Cognito · MinIO · Docker · Coolify · ESP32/PlatformIO

[Mobile App Repo](https://github.com/ivfrost/hydrolink-app) · [API Repo](https://github.com/ivfrost/hydrolink-api)

<details>
<summary><strong>Zest Music</strong>: A local-first Android music player inspired by Vanilla Music and Material Design 3</summary>

<br>

I started Zest Music because I wanted a more modern, native-feeling Android music player and a better everyday experience for browsing and listening to a personal library. One-handed controls and more flexible queue behavior are examples of the workflow details I care about.

Zest scans folders selected through Android's system picker and indexes music locally in SQLite. Artists, Albums, and Songs have their own views, with Recent and Most played, and album filtering that narrows the Songs list. Material 3 styling is used throughout, with Android system dynamic colors where available and a neutral fallback palette.

Artist pages show albums and artwork. When a file has no MusicBrainz artist ID, Zest searches MusicBrainz by artist name, then uses Wikidata to find images on Wikimedia Commons. Deezer is available as an optional artwork fallback.

The mini player expands into a full player with queue controls, shuffle, repeat, and fine-grained seeking. Playback continues in the background with Android media controls.

**Tech:** React Native · Expo · TypeScript · Expo Router · SQLite · Drizzle ORM · NativeTabs · NativeWind · react-native-audio-api

[App Repo](https://github.com/ivfrost/zest-music)

</details>
